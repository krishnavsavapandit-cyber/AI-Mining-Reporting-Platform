1 What the Platform Does

The CIL Multi-Agent Document Intelligence Platform is an enterprise automated reporting and knowledge extraction engine tailored for Coal India Limited (CIL) and its technical arm, Central Mine Planning and Design Institute (CMPDI). It autonomously ingests heterogeneous mining documentation across subsidiaries (ECL, BCCL, CCL, WCL, SECL, NCL, MCL, CMPDI), extracts structured metrics (Production, Overburden Removal, Stripping Ratios, Safety Incidents, Geological Reserves), detects cross-document numerical conflicts, and synthesizes evidence-backed reports and parliamentary responses.

2 Supported Document Formats

  • Digital PDF (.pdf): Ingested via high-speed PyMuPDF text stream extraction.
  • Scanned PDF / Images (.png, .jpg, .tiff): Routed through Tesseract OCR with adaptive image binarization.
  • Word Documents (.docx): Structured paragraph and tabular extraction via python-docx.
  • Excel Spreadsheets (.xlsx, .xls): Sheet, row, and cell metadata mapping via openpyxl/pandas.
  • Tabular CSV (.csv): Automated schema profiling and numeric parsing via pandas.

3 Ingestion & Multi-Agent Processing

When files are uploaded or seeded, the Manager Agent delegates work to specialized agents:

  1. Ingestion Agent: Extracts text, tabular structures, and generates chunked embeddings.
  2. Extraction Agent: Mines entities (Mines, Seams, Production MT, OBR M.Cum, Fatalities).
  3. Validation Agent: Evaluates cross-document variance (>5% flagged as discrepancies).
  4. Reporting / Inquiry Agent: Synthesizes reports with grounded citations.

4 Semantic & Hybrid Search

The Search Engine combines BM25 keyword term matching with dense cosine vector embeddings. Use subsidiary filters (e.g. ECL, BCCL) or document type selectors (Geological, Production, Safety) to narrow query scope.

5 AI Assistant & Evidence Grounding

The Assistant answers queries strictly from ingested source chunks. Every answer provides:
• Grounding Confidence Score (%)
• Verbatim Source Citations with exact Page & Chunk references
• Fallback to "Insufficient information found in the available documents." if query concepts are missing.

6 Semantic Classification Tags

[EXTRACTED FACT]

Verbatim empirical extraction backed by exact document, page number, and table cell coordinate.

[AI INTERPRETATION]

Analytical deduction synthesized by the LLM from multiple factual premises.

[AI RECOMMENDATION]

Operational advisory or mitigation suggested by the system requiring executive review.

[HUMAN APPROVED]

Formal sign-off recorded by a designated CIL Reviewing Officer / Admin.

7. Parliamentary & Ministry Inquiries -- Mandatory Human-In-The-Loop Protocol

GOVERNMENT COMPLIANCE MANDATE: All AI-generated responses for Lok Sabha, Rajya Sabha, or Parliamentary Standing Committee questions are explicitly stamped with:
DRAFT -- REQUIRES HUMAN VERIFICATION
An AI draft NEVER automatically becomes an official government submission. A designated Officer (Role: OFFICER or ADMIN) must review the grounded citations, verify against original borehole/DGMS logs, and click "Approve & Sign-off Draft" before external dissemination.

8 3-Tier AI Resiliency & Degraded Mode Behavior

In critical mining field operations where Internet or Cloud API connectivity is severed, the platform guarantees 100% operational uptime via automatic cascading fallback:

Tier 1: Google Gemini API (Primary Cloud AI) -- High-throughput synthesis when online.
  ↓ (On API 429 Quota Exceeded / 503 Network Timeout)
Tier 2: Open-Source Local Model (Ollama / vLLM / llama.cpp) -- Runs on local infrastructure via OpenAI-compatible endpoint.
  ↓ (On Local Model Server Offline / Unreachable)
Tier 3: Deterministic Grounded Engine (100% Offline Rule-Based) -- Pure Python RAG fallback with zero network/RAM overhead.
Demonstration Notice: Sample files preloaded in this sandbox environment are synthetic documents constructed for hackathon verification and benchmark evaluation. Production deployment requires linking to live Coal India Oracle/SAP ERP feeds, CMPDI CBM/Borehole databases, and DGMS incident records via enterprise connectors.
